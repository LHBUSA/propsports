MLB API

Schedules, live games, Statcast and model output.

MLB is the deepest dataset on the network: live game state, owned Statcast tables for batters and pitchers, game environment (weather, park factor, umpires), market data and the PropBetEdge Poisson model.

02 Endpoints

25 documented MLB routes.

All routes are GET on https://propsports-api.sales-fd3.workers.dev. Public routes need no key; the rest take X-API-Key or ?key=.

Schedule & live

  • GET
    /mlb/scheduleSchedule by date with probable pitchers, venue and linescore · Public
  • GET
    /mlb/schedule/todayToday's slate · Public
  • GET
    /mlb/games/liveGames currently in progress · Public
  • GET
    /mlb/lineupsPosted lineups and probable pitchers · Public

Game detail

  • GET
    /mlb/game/:pk/linescoreInning-by-inning linescore · Public
  • GET
    /mlb/game/:pk/boxscoreFull box score · Public
  • GET
    /mlb/game/:pk/playsMost recent plays (?limit) · Public

Players

  • GET
    /mlb/player/:id/statsSeason stats · Demo key
  • GET
    /mlb/player/:id/gamelogGame log · Demo key

Statcast

  • GET
    /mlb/statcast/battersExit velocity, barrel %, xBA / xSLG / xwOBA, last-7 and handedness splits · Public
  • GET
    /mlb/statcast/pitchersPitcher Statcast table with pagination · Public

Game environment

  • GET
    /mlb/weatherWind, temperature and park factor for one park · Public
  • GET
    /mlb/weather/allWeather for every game on the slate · Public
  • GET
    /mlb/umpiresUmpire crews by game · Public

Market data

  • GET
    /mlb/oddsGame lines: spread, total, moneyline · Public
  • GET
    /mlb/odds/hrHome-run props, best book across DraftKings and FanDuel · Public
  • GET
    /mlb/odds/totalbasesTotal-bases props · Public
  • GET
    /mlb/odds/hitsHits props · Public
  • GET
    /mlb/odds/strikeoutsPitcher strikeout props · Public
  • GET
    /mlb/odds/rbiRBI props · Public
  • GET
    /mlb/odds/allAll prop markets combined · Public
  • GET
    /mlb/odds/playerOne player across prop markets (?name) · Public

Model output

  • GET
    /mlb/odds/modelPropBetEdge Poisson model prices (?market, ?player, ?direction) · Public
  • GET
    /mlb/odds/model/topTop model OVER plays · Public
  • GET
    /mlb/odds/model/playerOne player across model markets (?name) · Public
