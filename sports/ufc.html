02 Endpoints

14 documented UFC routes.

All routes are GET on https://ufc-api.propbetedge.ai. Public routes need no key; the rest take a UFC platform key.

Events & cards

  • GET
    /v1/ufc/eventsEvents (?status=upcoming) · Public
  • GET
    /v1/ufc/events/:id/cardFight card · Public
  • GET
    /v1/ufc/events/:id/weigh-insEvent weigh-ins · Public
  • GET
    /v1/ufc/weigh-insWeigh-in results · Public
  • GET
    /v1/ufc/resultsResults · Public
  • GET
    /v1/ufc/rankingsOfficial rankings snapshot · Public

Fighters & bouts

  • GET
    /v1/ufc/fightersFighters · Public
  • GET
    /v1/ufc/fighters/:idFighter profile · Public
  • GET
    /v1/ufc/fighters/:id/historyFight history and career stats · Public
  • GET
    /v1/ufc/bouts/:id/statsRound-by-round bout statistics · Public

Fight DNA & intelligence

  • GET
    /v1/ufc/dna/metricsFight DNA metric definitions · Public
  • GET
    /v1/ufc/fighters/:id/dnaFighter DNA (not a pick, price or probability) · API key
  • GET
    /v1/ufc/events/:id/intelligenceCard intelligence · API key
  • GET
    /v1/ufc/bouts/:id/ledgerFight state ledger checkpoints · API key
