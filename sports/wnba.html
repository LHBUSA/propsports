02 Endpoints

25 documented WNBA routes.

All routes are GET on https://propsports-api.sales-fd3.workers.dev. Public routes need no key; the rest take X-API-Key or ?key=.

Schedule & live

  • GET
    /wnba/todayToday's slate (or the next slate) · Public
  • GET
    /wnba/scheduleSchedule · Public
  • GET
    /wnba/seasonSeason context · API key
  • GET
    /wnba/games/:idGame detail · API key
  • GET
    /wnba/games/:id/liveLive game state · API key
  • GET
    /wnba/games/:id/eventsPlay-by-play events · API key
  • GET
    /wnba/games/:id/boxscoreBox score · API key
  • GET
    /wnba/games/:id/shotsShot events · API key
  • GET
    /wnba/matchups/:idMatchup detail · API key

Teams & standings

  • GET
    /wnba/standingsStandings · API key
  • GET
    /wnba/playoffsPlayoff picture · API key
  • GET
    /wnba/teamsTeams · API key
  • GET
    /wnba/teams/:idTeam profile · API key
  • GET
    /wnba/teams/:id/rosterRoster · API key

Players

  • GET
    /wnba/playersPlayers · API key
  • GET

  • GET
    /wnba/stats/playersPlayer statistics · API key
