02 Endpoints

13 documented NBA routes.

All routes are GET on https://propsports-api.sales-fd3.workers.dev. Public routes need no key; the rest take X-API-Key or ?key=.

Schedule & live

  • GET
    /nba/scheduleScoreboard by date (playoffs, then regular season) · Public
  • GET
    /nba/schedule/todayToday's slate · Public
  • GET
    /nba/games/liveGames in progress · Public

Game detail

  • GET
    /nba/game/:id/summaryGame summary with header · Public
  • GET
    /nba/game/:id/boxscoreNormalized box score with computed TS% and USG% · Public
  • GET
    /nba/game/:id/playsPlay-by-play with court coordinates and event category · Public
  • GET
    /nba/game/:id/shotchartMade and missed shots with x/y coordinates · Public
  • GET
    /nba/game/:id/lineupOn-court five reconstructed from starters and substitutions (estimated) · Public
  • GET
    /nba/game/:id/winprobWin-probability series (ESPN source) · Public
  • GET
    /nba/game/:id/hustleHustle box when the source allows it (may return available:false) · Public

Players & markets

  • GET
    /nba/leadersLeague leaders (?stat, ?season) · API key
  • GET
    /nba/player/:id/statsYear-over-year player stats · API key
  • GET
    /nba/oddsGame lines · API key
